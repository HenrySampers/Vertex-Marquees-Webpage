Website for Vertex Marquees (owned by Luke Cahill), a marquee hire business based in Limerick, Ireland.

**Why:** Building a professional web presence for a small marquee hire business.

**How to apply:** Focus on premium/elegant aesthetics matching the dark gold brand palette. Keep changes minimal and on-brand.

Key details:
- Stack: PHP, Bootstrap 5, custom CSS (no frameworks like Laravel/composer)
- Files: index.php, services.php, gallery.php, contact.php, process/send-quote.php, process/mailer.php, includes/config.php, includes/header.php, includes/footer.php, css/styles.css, js/lightbox.js
- Brand: Black/dark grey + gold accent (#C9A96E), fonts: Cormorant Garamond + Raleway
- Business email: VertexMarquees@gmail.com, Phone: 083 320 5052
- Social links in config.php are placeholders ('#') — need real URLs from Luke
- SMTP email configured in config.php — needs Gmail App Password, set $smtp_enabled = true to activate
- Packages: Single Party, Double Party, Single Event, Double Event
